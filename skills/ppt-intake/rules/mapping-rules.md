# 内容映射决策规则（Mapping Rules）

第 2 步「对齐分析」时用。目标：把每份材料的每一页归入四类动作之一，
并给出可核对的理由。判断顺序自上而下，命中即停。

## 判定流程（对材料的每一页）

```
材料页 P
 ├─ 1. 与基准现有页重复？ ──→ 内容/数据谁更新？
 │      基准更新或等价 ........→ drop（理由：与第N页重复）
 │      材料更新/更全 .........→ update（把新材料合并进基准第N页文案）
 │      两边都有独有信息 .......→ update（合并两者，注意 R4 预算）
 │      同主题但口径冲突 .......→ conflict（列两边值，请用户裁决）
 ├─ 2. 与基准 PPT 的目标相关？ ──否→ drop（理由：超出本 PPT 范围）
 ├─ 3. 基准有同角色页能承载？ ──是→ append（clone 该角色页 + 填充）
 └─ 4. 承载不了（信息密度过高/需独占图表）
        → 优先拆成多页 append；
        → 仍不行 → conflict（说明局限，附建议）
```

## 页面角色识别（inspect 清单已给出 `role`，复核要点）

| role | 特征（来自清单） | 常作为克隆源 |
|---|---|---|
| cover | 形状少 + 超大标题（≥36pt） | 新封面/新章节封面 |
| section | 仅 1–2 个短文本框 | 新章节隔页 |
| content | 多个正文框 | 普通内容新增页 |
| stats | 有 60pt+ 数字形状 | 数据/成果页 |
| closing | 页尾 + 短文本 | 结尾致谢页 |

## update 的写法（改现有页）

- 只改**内容性文本**（数据、结论、名单），不动结构性文本（章节编号、固定栏目名）。
- 一页多个候选替换框时，用 `shape_id` 精确定位（清单里有），不要全文匹配。
- 合并两边信息时以基准句子为骨架、把材料的新事实嵌入，**不是**把材料句子整段贴入。

## append 的写法（克隆新增页）

- 选克隆源：角色相同 + 文本框数量/布局最接近材料页信息结构的基准页。
- 替换映射逐框写 `old_text`（**抄清单里 shape 的 exact text，含换行**）→ `new_text`。
- 材料页塞不下的内容 → 拆两页克隆，不要在单页超预算硬塞（R4）。

## 去重信号

- 标题相似度（忽略标点/空白）≥ 高度相似 → 进入重复判定。
- 数字口径不同（如市占率 18% vs 22%）→ 优先信**更新日期近**的一方；
  都没日期 → conflict。

## 冲突的最低门槛

以下情况**必须**标 conflict，不许自行拍板：
- 金额/日期/百分比等硬数据不一致
- 结论方向相反（一方"增长"一方"下滑"）
- 涉及客户名/人名/产品名的版本差异
